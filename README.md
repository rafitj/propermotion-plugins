# Proper Motion plugins

Install Virgo once to add Proper Motion's hosted MCP connection and its agent
improvement workflows to Codex or Claude Code.

Copy this prompt into either client:

> Connect Proper Motion to this AI client through the Virgo plugin. Open the
> setup guide below and follow exactly one branch for the product running this
> session: Claude Code or Codex. Install or update the plugin, authenticate its
> hosted Virgo MCP server, and verify the connection with the read-only
> `virgo_get_workspace_context` tool:
> https://github.com/rafitj/propermotion-plugins/blob/main/GETTING_STARTED.md

See [GETTING_STARTED.md](./GETTING_STARTED.md) for the complete product-specific
installation and verification contract.
